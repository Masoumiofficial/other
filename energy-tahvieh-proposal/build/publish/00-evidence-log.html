۶. مواردی که تا زمان دسترسی تأیید نشده‌اند (فهرست صریح)

  1. Core Web Vitals واقعی (LCP/INP/CLS) در موبایل و دسکتاپ — میدانی و آزمایشگاهی
  2. حجم کل صفحه، تعداد درخواست‌ها، اندازه DOM، TTFB، زمان پاسخ سرور
  3. نسخه PHP / MySQL / وردپرس / ووکامرس / قالب / هر افزونه
  4. وضعیت به‌روز بودن هسته و افزونه‌ها؛ وجود آسیب‌پذیری شناخته‌شده
  5. نرخ خطای ۵xx/۴xx در لاگ سرور؛ خطاهای PHP و کنسول JS
  6. کیفیت و محدودیت منابع هاست (CPU/RAM/IO، نسخه Apache/LiteSpeed/Nginx)
  7. وضعیت کش سرور/صفحه/آبجکت و وجود CDN
  8. فرایند بکاپ‌گیری، دوره نگه‌داری، و آزمایش بازیابی
  9. دسترسی‌ها و نقش‌های کاربری، احراز هویت دومرحله‌ای، امنیت wp-admin
  10. وجود/اعتبار نماد اعتماد الکترونیکی (اینماد) و ساماندهی
  11. داده‌های Search Console: پوشش ایندکس، کوئری‌ها، impressions، CTR، موقعیت‌ها
  12. داده‌های Analytics/GTM: جلسات، منابع ترافیک، نرخ تبدیل، رهاشدن سبد، جست‌وجوی بدون نتیجه
  13. داده‌های واقعی فروش: GMV، میانگین سبد، تکرار خرید، سهم کانال‌ها
  14. درگاه‌های پرداخت فعال و نرخ موفقیت تراکنش
  15. روش‌های ارسال و نرخ واقعی تحویل
  16. ساختار دیتابیس، اندازه جداول، وجود orphan meta و transients
  17. وضعیت واقعی «خرید اقساطی» (آیا فعال است یا فقط یک برچسب فوتر؟)
  18. ساختار سازمانی، تیم فعلی، پیمانکاران پیشین و سوابق تحویل
  19. بودجه بازاریابی و ابزارهای موجود
