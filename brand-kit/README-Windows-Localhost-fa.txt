آهنگ‌بان — بازکردن پیش‌نمایش روی ویندوز

۱) فایل brand-kit.zip را Extract کنید.
۲) وارد پوشهٔ brand-kit شوید.
۳) روی start-localhost.bat دوبار کلیک کنید؛ پنجرهٔ جداگانهٔ سرور باز می‌شود.
۴) پس از چند لحظه مرورگر نشانی http://localhost:8000/index.html را باز می‌کند.
۵) پنجرهٔ سرور را تا پایان کار باز نگه دارید؛ برای خاموش‌کردن، در همان پنجره Ctrl+C بزنید یا آن را ببندید.

پیش‌نیاز localhost: Python 3 برای ویندوز. اسکریپت ابتدا لانچر py و بعد python را امتحان می‌کند.
اگر Python نصب نیست، فایل BAT، index.html را مستقیم باز می‌کند؛ برای دیدن پیش‌نمایش ایستا، سرور الزامی نیست.

همهٔ فایل‌ها محلی‌اند و برای پیش‌نمایش به اینترنت نیاز ندارند. اگر پورت ۸۰۰۰ اشغال بود، پنجرهٔ سرور را ببندید یا مقدار PORT داخل start-localhost.bat را تغییر دهید.
