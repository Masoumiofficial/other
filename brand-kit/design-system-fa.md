# راهنمای سیستم طراحی دیجیتال آهنگ‌بان

**نسخهٔ ۱٫۱ · همراه سیستم برند**\
هدف این راهنما یک زبان بصری قابل‌اجرا برای محصول و پیش‌نمایش است؛ قبل از عرضه، روی دستگاه واقعی و با محتوای دارای مجوز آزمون شود.

## ۱. منابع فنی

- `assets/brand-tokens.css` — توکن‌های CSS و کامپوننت پایه.
- `assets/brand-tokens.json` — توکن‌های ماشین‌خوان.
- `assets/brand-fonts.css` — بارگذاری محلی فونت سازمانی.
- `assets/fonts/` — فایل‌های Vazirmatn و مجوز OFL.
- `index.html` — پیش‌نمایش بدون CDN و بدون وابستگی آنلاین.

## ۲. پالت و کاربرد

| توکن | مقدار | کاربرد |
|---|---|---|
| `--hb-blue` | `#185ADB` | اقدام اصلی، لینک روی سطح مناسب، active و نشان رنگی |
| `--hb-blue-dark` | `#1248B2` | hover و لینک متن روی سفید |
| `--hb-blue-pale` | `#EAF1FF` | سطح فعال و پس‌زمینهٔ ملایم |
| `--hb-ink` | `#111111` | متن اصلی و سطح تیره |
| `--hb-white` | `#FFFFFF` | زمینه و متن روی آبی/مشکی |
| `--hb-dark` | `#222222` | سطح تیرهٔ ثانویه |
| `--hb-text-muted` | `#666666` | متن فرعی روی سفید |
| `--hb-surface` | `#F4F4F4` | سطح کارت |
| `--hb-line` | `#E5E5E5` | مرز |

لوگو سه حالت دارد: رنگی، مشکی و سفید. رنگ دیگری به لوگو اضافه نکنید و از گرادینت استفاده نکنید.

## ۳. تایپوگرافی

```css
font-family: "Ahangban Vazirmatn", Tahoma, Arial, sans-serif;
```

فونت اصلی محلی است و در `assets/fonts/` با مجوز OFL 1.1 قرار دارد. برای فارسی از وزن‌های ۴۰۰ تا ۹۰۰ استفاده کنید. عنوان‌ها کوتاه و متن اصلی با فاصلهٔ خط ۱٫۷ تا ۱٫۹ باشد.

## ۴. شبکه و فاصله

- گام اصلی: ۴، ۸، ۱۲، ۱۶، ۲۴، ۳۲، ۴۸ و ۶۴ پیکسل.
- شعاع کنترل: ۸ پیکسل؛ کارت: ۱۶؛ پنل: ۲۴؛ برچسب: کپسولی.
- عرض خواندن متن بلند: حدود ۶۰ تا ۷۵ نویسه.
- حاشیهٔ موبایل: ۱۶ تا ۲۰ پیکسل.
- چیدمان: RTL، واکنش‌گرا و مبتنی بر `margin-inline`/`padding-inline`.

## ۵. لوگو و نشان در محصول

- انتخاب پیش‌فرض روی زمینهٔ روشن: `ahangban-logo-horizontal-color.svg`.
- زمینهٔ تیره: `ahangban-logo-horizontal-reverse.svg`.
- چاپ و اسناد رسمی: `ahangban-logo-horizontal.svg`.
- قاب کوچک: `ahangban-mark-color.svg` یا نسخهٔ تک‌رنگ.
- حداقل ناحیهٔ لمس آیکن: ۴۴×۴۴ پیکسل؛ خود نشان حداقل ۲۴ پیکسل.
- فضای امن لوگو را با ارتفاع میلهٔ بلند نشان تعیین کنید.
- متن لوگو به فونت محلی وابسته است؛ برای چاپ نهایی، outline/path تولید کنید.

## ۶. اجزای رابط

### دکمهٔ اصلی

```css
.button-primary {
  min-height: 48px;
  padding: 12px 20px;
  border: 2px solid #185ADB;
  border-radius: 999px;
  background: #185ADB;
  color: #FFFFFF;
  font: 700 1rem/1.4 "Ahangban Vazirmatn", Tahoma, sans-serif;
}
```

متن دکمه باید فعل روشن داشته باشد: «پیدا کن»، «گوش بده»، «ارسال برای بررسی». روی آبی فقط متن سفید قرار دهید.

### کارت اثر

ترتیب پیشنهادی: کاور مجاز ← نوع محتوا/نسخه ← عنوان ← هنرمند/سازنده ← اقدام تأییدشده. اطلاعات نامطمئن را حدس نزنید.

### برچسب دسترسی

نمونه‌ها: «پخش در دسترس»، «دانلود مجاز»، «اجازه در حال بررسی». برچسب باید از رکورد حقوقی بیاید و فقط با رنگ مشخص نشود.

### جست‌وجو و خطا

- label مستقل از placeholder.
- placeholder: «نام آهنگ، هنرمند یا آلبوم».
- خطا: «پخش انجام نشد. اتصال را بررسی کن و دوباره تلاش کن.»
- مجوز نامشخص: «این محتوا تا روشن‌شدن اجازهٔ انتشار نمایش داده نمی‌شود.»

## ۷. RTL و دسترس‌پذیری

- سند فارسی: `lang="fa" dir="rtl"`.
- URL، کد و شناسه در محدودهٔ LTR نمایش داده شوند.
- focus با خط دور آبی یا خنثیِ قابل‌دیدن مشخص شود.
- متن جایگزین تصاویر محتوایی نوشته شود؛ تصویر تزئینی `alt=""` داشته باشد.
- صدا autoplay نشود و حرکت مداوم وجود نداشته باشد.
- در بزرگ‌نمایی ۲۰۰٪ و عرض ۳۲۰ پیکسل، اسکرول ناخواسته نباشد.
