# پکیج برند آهنگ‌بان / Ahangban

نسخهٔ ۱٫۲ · ۷ اکتبر ۲۰۲۶

این پوشه یک پکیج آفلاین برای بازبینی هویت، نمونه‌سازی اولیه، آماده‌سازی همکاری و ثبت تصمیم‌های محتوایی آهنگ‌بان است. **این پکیج محصول فعال، مجوز انتشار اثر، ثبت علامت تجاری یا تأیید DNS نیست.**

## شروع سریع

1. فایل `شروع-از-اینجا.txt` را بخوانید.
2. برای مرور تصویری، `index.html` را باز کنید.
3. برای کتاب برند، `brand-book.html` و برای برنامهٔ کسب‌وکار، `strategy.html` را باز کنید.
4. برای چاپ، از منوی Print مرورگر استفاده کنید؛ هر دو HTML مستقل و بدون اینترنت کار می‌کنند.
5. برای همکاری با هنرمند، صاحب اثر، ناشر یا لیبل از `tools/چک‌لیست-همکاری-موسیقی.html` استفاده کنید.
6. فایل `tools/کاتالوگ-مادر-آهنگ‌بان.xlsx` را در Excel یا LibreOffice باز کنید.

## باز کردن در ویندوز

- روش ساده: روی `index.html` دوبار کلیک کنید.
- روش مطمئن‌تر برای فونت و مسیرها: `start-localhost.bat` را اجرا کنید. اگر Python 3 نصب باشد، پیش‌نمایش روی `http://localhost:8000` باز می‌شود.
- روش دستی: در همین پوشه `py -m http.server 8000` یا `python -m http.server 8000` را اجرا کنید.

## اصول غیرقابل‌مذاکرهٔ محتوا

- نام هنرمند یا اثر در کاتالوگ، به‌تنهایی مجوز انتشار نیست.
- پخش، دانلود، ویدئو، پادکست، ریمیکس، تبلیغ و استفادهٔ تجاری باید جداگانه برای همان اثر، همان نوع استفاده، قلمرو و بازهٔ زمانی بررسی شوند.
- اگر مدرک یا وضعیت مشخص نیست، عبارت درست «در انتظار بررسی» یا «فعلاً منتشر نشود» است؛ دکمهٔ پخش/دانلود نباید صرفاً به‌دلیل وجود یک نام فعال شود.
- مدل تأمین محتوا و قراردادهای آهنگ‌بان هنوز نهایی نشده‌اند؛ داده‌های فایل Excel نمونه و عملیاتی‌اند، نه فهرست مجاز واقعی.
- دامنهٔ `ahangban.ir` طبق اعلام مالک خریداری شده است؛ DNS، SSL، ثبت علامت و حق انحصاری نام در این بسته تأیید نشده‌اند.
