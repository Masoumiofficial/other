# چک‌لیست آماده‌سازی محتوا و مجوز

**نسخهٔ کاری ۱٫۱ · برای ثبت فرایند، نه مشاورهٔ حقوقی**

این چک‌لیست بخشی از جهت اعتماد آهنگ‌بان است. وجود آهنگ، تصویر یا نام هنرمند در وب یا شبکهٔ اجتماعی به‌معنای اجازهٔ بارگذاری، پخش یا دانلود نیست. مجوز باید برای همان اثر، همان نسخه، همان نوع استفاده و قلمرو/مدت موردنظر روشن و مستند باشد.

## ۱. شناسنامهٔ هر مورد

- شناسهٔ داخلی محتوا:
- نوع محتوا: تک‌آهنگ / آلبوم / موزیک‌ویدئو / پادکست / ریمیکس / اجرا / مورد دیگر
- عنوان دقیق اثر و نسخه:
- هنرمند/سازنده/مهمان:
- مالک یا نمایندهٔ حقِ فایل ضبط‌شده:
- صاحب حقِ آهنگسازی/ترانه، تصویر یا اجرا (در صورت ارتباط):
- منبع فایل و تاریخ دریافت:
- کشور/قلمرو دسترسی:
- مدت مجوز و تاریخ پایان:
- نام و راه تماس طرف قرارداد:
- شناسه و محل نگهداری قرارداد یا اجازهٔ کتبی:
- وضعیت بازبینی: ناقص / در حال بررسی / تأیید برای نوع استفادهٔ مشخص / ردشده / منقضی

**فایل صوتی/ویدئویی تا وقتی وضعیت متناسب با نوع استفاده تأیید نشده، در آرشیو قابل انتشار قرار نگیرد.**

## ۲. ماتریس نوع استفاده

برای هر ردیف جداگانه «بله/خیر/نامشخص» ثبت کنید؛ تأیید یک نوع را به نوع دیگر تعمیم ندهید.

| نوع استفاده | پرسش کنترلی |
|---|---|
| پخش آنلاین صوت | اجازهٔ پخش عمومی/آنلاینِ این ضبط و اثر، روی سرویس و در قلمرو هدف روشن است؟ |
| دانلود فایل صوتی | اجازهٔ ارائهٔ فایل برای ذخیرهٔ کاربر صریح است؟ حق پخش به‌تنهایی کافی نیست. |
| موزیک‌ویدئو | حق فایل ویدئو، موسیقی هم‌زمان، تصویر افراد/لوکیشن و نمایش در پلتفرم روشن است؟ |
| پادکست | میزبان، مهمان، موسیقی پس‌زمینه، کلیپ‌ها و حق توزیع هر قسمت روشن است؟ |
| ریمیکس | اجازهٔ استفاده از ضبط/استم‌ها، ساخت نسخهٔ مشتق، نسبت‌دادن، انتشار و درآمدزایی صریح است؟ |
| کاور/بازخوانی | حق اثر پایه و اجازه‌های لازم برای ضبط، پخش، دانلود و قلمرو بررسی شده است؟ |
| پیش‌نمایش/تبلیغ | استفاده از بخشی از اثر، کاور، نام یا تصویر هنرمند برای تبلیغ مجاز است؟ |
| استفادهٔ تجاری/B2B | مجوز برای استفادهٔ تجاری، رویداد یا مشتری سازمانی جداگانه پوشش داده شده است؟ |

## ۳. دروازه‌های انتشار

### پیش از دریافت

- [ ] فرستنده هویت و اختیار نمایندگی خود را توضیح داده است.
- [ ] منبع فایل و نسخهٔ درست معلوم است.
- [ ] فایل از مسیر امن دریافت شده؛ لینک عمومی مشکوک تنها منبع اثبات نیست.

### پیش از ورود به کاتالوگ

- [ ] عنوان، نسخه، هنرمند، صاحب ضبط و متادیتا بررسی شده‌اند.
- [ ] قرارداد/اجازه قابل‌ردیابی و برای قلمرو، مدت و پلتفرم هدف معتبر است.
- [ ] پخش، دانلود، ویدئو، پادکست، ریمیکس و تبلیغ جداگانه ارزیابی شده‌اند.
- [ ] دسترسی جغرافیایی و تاریخ آغاز/پایان در سامانه ثبت شده‌اند.
- [ ] تصویر کاور، عکس و هر عنصر بیرونی نیز اجازهٔ مربوط را دارد.

### پیش از انتشار و هنگام پایان مجوز

- [ ] اقدام‌های محصول فقط برای نوع استفادهٔ تأییدشده فعال‌اند.
- [ ] نسبت‌دادن اثر و نام‌ها دقیق است.
- [ ] مسیر گزارش و حذف/توقف دسترسی آماده است.
- [ ] تاریخ یادآوری انقضا و مسئول بازبینی ثبت شده‌اند.
- [ ] با پایان مجوز، تمدید یا برداشتن محتوا طبق قرارداد انجام می‌شود.

## ۴. واژگان وضعیت در رابط

- **تأییدنشده:** اجازه بررسی نشده؛ برای انتشار فعال نیست.
- **در حال بررسی:** مدرک دریافت شده اما تصمیم نهایی ثبت نشده؛ دسترسی عمومی فعال نیست.
- **تأیید برای پخش:** فقط پخش، در محدوده و مدت ثبت‌شده.
- **تأیید برای دانلود:** دانلود صریحاً مجاز است؛ این برچسب جای حق پخش یا ویدئو را نمی‌گیرد.
- **تأیید برای ویدئو/ریمیکس/تبلیغ:** هر مورد جداگانه و با مدرک مربوط ثبت شود.
- **منقضی/متوقف:** اقدام مربوط غیرفعال و وضعیت برای تیم داخلی ثبت شود.

از عبارت «قانونی»، «رسمی» یا «مجاز» در پیام عمومی فقط وقتی استفاده کنید که مسئول مربوط مدرک و دامنهٔ مجوز را بررسی کرده باشد.

## ۵. رسیدگی به گزارش یا درخواست حذف

۱. زمان، لینک، نام گزارش‌دهنده و موضوع را ثبت کنید.\
۲. دسترسی به مورد را تا بررسی طبق سیاست و شرایط لازم محدود کنید.\
۳. مالک محتوا، قرارداد، نوع استفاده و قلمرو را بررسی کنید.\
۴. اقدام، مسئول و دلیل را ثبت کنید؛ گزارش‌دهنده را از نتیجهٔ قابل‌اعلام باخبر کنید.\
۵. اگر تکرار یا اختلاف وجود دارد، موضوع را به مشاور حقوقی/مسئول حقوقی بسپارید.

برای زمان پاسخ، SLA یا نتیجه‌ای که هنوز تعیین نشده وعده ندهید.

## ۶. موارد باز آهنگ‌بان

- مدل تأمین محتوا هنوز مشخص نشده است.
- مالک حقوقی برند و طرف قراردادها مشخص نشده‌اند.
- محدودهٔ دقیق دسترسی جغرافیایی و روش رسیدگی حقوقی باید توسط صاحب پروژه و مشاور مناسب تعیین شود.

قالب فنی ثبت هر اثر در `catalog/track-intake-template.csv` است؛ همهٔ هنرمندان فهرست اولیه در وضعیت حقوقی **تأییدنشده** هستند.
